使用说明
从创建会话到飞书联动的完整操作指南

快速开始

Iris 是连接飞书与本机 Agent 的个人助理。每个会话都会自动启动已配置的 Agent，既能由你直接使用，也能先接待通过飞书联系你的人。

1保护设置首次进入先设置访问密码，也可在确认风险后跳过。
2确认 Agent首次使用会优先自动选择本机的 Codex，其次选择 Claude Code。
3配置飞书创建机器人并填写开发者 open_id，供个人助理建群与鉴权。
4开始对话网页新建会话，或直接向飞书机器人发送消息。
推荐习惯

短命令直接在黑色终端里输入；长提示、带换行的文字、说明性任务放到下方输入框再发送。

网页终端

会话列表

左侧只显示当前活跃会话。点击会话卡片即可切换；不再保留已退出或失败的历史会话。

终端区域

黑色区域是 xterm 终端，支持常规键盘输入、复制粘贴、方向键和 TUI 程序操作。

下方输入框

适合发送多行文本。点击 Send 或按 Command/Ctrl + Enter，会把内容提交给终端并自动回车。

快速命令

下方横向命令条可以保存常用命令。点击 + 添加，点击命令片段会填入输入框，点击 × 删除。

飞书联动

其他人私聊机器人后，Iris 会创建“与某某的对话”群聊，将对方、开发者和机器人加入群中，并自动把私聊消息转发给群内 Agent。后续私聊会继续复用这个群聊和 Agent 会话。

应用能力

扫码创建或选择已有应用时，会打开带应用模板的飞书确认页，由飞书流程补齐基础消息、发消息、长连接事件和卡片回调配置。群里直接发消息需要额外开通“获取群组中所有消息（敏感权限）”。

普通私聊：自动建立或复用联系人群聊，并把消息交给 Agent。

开始 会话名：创建你的开发会话，默认开启开发者模式并关闭艾特模式。

联系人群聊：默认开启艾特模式，只有 @Iris 的消息才会触发 Agent；可在开发者模式下关闭。

直接把机器人拉进群：自动绑定新 Agent 会话，默认开启艾特模式。

开发者模式：由配置的开发者通过卡片按钮开关；开启后显示目录、模型、推理等级、Agent 重启、终端快捷键和自定义快捷键。

等待通知怎么判断

终端在一段时间内没有新的输出后，会被认为进入 waiting。快速等待适合普通命令，保守等待适合 Codex/TUI 等输出节奏更复杂的场景。

飞书推送机制

什么时候推送

会话开启“通知”后，每次输入会把状态切回 running；终端输出稳定一段时间后进入 waiting。达到快速等待或保守等待时间后，系统会准备一条飞书等待通知。

推到哪里

联系人消息与 Agent 回复都进入“与某某的对话”群；开发会话则进入对应会话群或开发者通知目标。

消息标题

通知卡片标题默认是会话名。用户回复后终端重新运行时，会把同一张卡片标题临时改成“会话名（Running）”；本轮再次进入 waiting 后恢复会话名。

消息正文

正文是当前轮终端内容，不是完整历史。系统优先使用后端维护的终端屏幕快照，浏览器页面打开与否不会影响基础数据源。

锚点规则

每次提交输入时会记录“上次输入文本”和“输入前的屏幕快照”。推送时优先从屏幕快照里找到这次输入的回显，只截取它后面的回复；找不到输入回显时，会用本轮原始输出作为兜底，避免把上一轮内容推出来。

更新规则

同一轮第一次完成会新发主卡片；后续内容变化会 Patch 更新同一张卡片，并单独提示“任务已完成”。Agent 回合优先由 Hook 精确感知，普通终端使用短暂静默作为完成兜底。

卡片操作

普通模式保留刷新和开发者模式按钮。开发者模式开启后，才显示工作目录、模型选择、Agent 重启、艾特模式、终端快捷键和自定义快捷键。

内容清理

推送前会清理终端控制字符、重复行、空白分隔、Codex/TUI 临时状态行，并按“通知过滤规则”处理匹配内容。邮箱样式文本会被替换成 [email]。

长度限制

正文最多保留“通知最大行数”里的尾部内容，同时还有总字符保护。超过限制时会带 [truncated] 前缀，表示前面的内容已被裁剪。

配置说明

首次引导先设置访问密码，再选择必需的 Agent。完成后可通过左下角齿轮配置飞书和工作目录。

测试飞书配置保存前可发送测试卡片，并检查“获取群组中所有消息（敏感权限）”是否真实生效。

图片与文件

网页粘贴图片

在终端区域粘贴图片，会上传到当前会话目录，并把图片路径写入终端。粘贴到下方输入框时，会把路径插入输入框。

飞书图片

从飞书发送图片时，图片会下载到用户数据目录的 data/uploads/{session_id}/lark/，再把本地路径交给终端使用。

路径用途

路径是给本机命令或终端程序读取图片用的。如果要分析图片，可以在路径后补充“请分析这张图”。

清理规则

删除会话时，会同步删除该会话的上传目录。

数据库辅助文件

iris.db-wal 和 iris.db-shm 是 SQLite 运行时文件。服务运行时出现是正常现象，不需要手动处理。

常见问题

问题：配置保存时提示数值无效

解决：检查快速等待、保守等待、通知最大行数是否为空或小于 1。它们都是正整数，单位分别是毫秒和行数。

问题：飞书发送消息后没有响应

解决：先点击“测试飞书配置”。如果“群所有消息权限”失败，需要在飞书后台为当前 App 开通“获取群组中所有消息（敏感权限）”，发布/审批后再保存配置。只 @ 机器人可用但普通群消息无响应时，基本就是缺这个权限。

问题：飞书通知内容太长

解决：调小通知最大行数，或在“通知过滤规则”里加入噪声输出的匹配规则。

问题：终端尺寸或显示不正常

解决：刷新页面后重新选择会话。页面加载和窗口变化时会自动适配终端列数和行数。

问题：粘贴图片后没有看到路径

解决：确认当前选中的是在线会话。粘贴到终端区域会把路径写入终端；粘贴到下方输入框会把路径插入输入框。
